# 传感器多目标跟踪：航迹关联与生命周期管理

纯 Go 标准库实现的逐帧多目标跟踪器，附带单一静态 HTML 回放页（原生 HTML/CSS/JS，无任何第三方库）。

## 运行

```bash
go test ./...        # 运行全部自动化测试
go run ./cmd/replay  # 生成 replay.html（120 帧演示场景）
open replay.html     # 浏览器中逐帧回放
```

回放页支持播放/暂停、逐帧步进（←/→ 方向键，空格播放暂停）、拖动进度条与倍速，
并以高亮环标出**新生 / 确认 / 遮挡恢复 / 消亡**事件。

## 系统结构

```
tracker/    跟踪核心：卡尔曼滤波、匈牙利全局关联、生命周期管理
scenario/   带真值标签的场景生成（交叉、遮挡、新生/消亡、杂波）与身份保持评估
cmd/replay/ 回放页生成器（go:embed 内嵌模板，数据全部内联）
```

每帧处理流程：预测 → 构建门控代价矩阵 → 两阶段全局最优关联 → 状态更新 →
消亡判定 → 新航迹创建 → 记录快照。

## 关联算法选择

**全局最优二分图匹配（匈牙利算法，O(n³)），而非贪心最近邻。**
贪心策略在两条航迹预测位置接近、观测落在双方关联代价重叠区时，会按处理顺序
抢占观测，导致交叉场景下两条航迹身份互换。匈牙利算法最小化所有可行配对的
总代价，交叉瞬间"直行"配对的代价之和显著小于"交换"配对，身份得以保持
（`tracker/hungarian.go`，`TestHungarianBeatsGreedy` / `TestCrossingNoIdentitySwap`）。

**关联代价**：观测与航迹预测之间的马氏距离平方 `d² = y'S⁻¹y`
（y 为新息，S 为新息协方差），它随航迹不确定性自动缩放门限——
遮挡滑行期间协方差增大，门限随之放宽，这是遮挡后能重新关联的关键。

**不可行匹配处理**：代价矩阵补全为 (航迹数+观测数) 阶方阵，显式加入
"航迹未关联"与"观测未关联"两类虚拟节点（代价各为门限 Gate），
不可行项置为大数。匈牙利算法求全局最优后，任何代价 ≥ Gate 的配对都不会
被强制关联，航迹与观测允许同时保持未关联状态
（`globalAssignment`，`TestGlobalAssignmentRejectsInfeasible`）。

**两阶段关联**：第一阶段确认航迹关联全部观测，第二阶段暂态航迹只关联
剩余观测。新生暂态航迹初速未知、协方差涣散、门限范围大，若与确认航迹
同场竞价，容易凭较小的马氏距离抢走确认航迹的观测（身份劫持）；
两阶段从结构上杜绝了这一问题。

**状态估计**：匀速模型卡尔曼滤波（状态 [x, y, vx, vy]，离散白噪声加速度
过程模型），仅依赖标准库手写 4×4 矩阵运算。

## 生命周期判定阈值（`tracker.DefaultConfig`）

| 参数 | 默认值 | 含义 |
|---|---|---|
| `ConfirmHits` | 3 | 暂态航迹**连续**关联 3 帧才确认，单帧噪声点不会建轨 |
| `TentativeMaxMisses` | 2 | 暂态航迹连续 2 帧未关联即剪除，防止杂波堆积 |
| `MaxMisses` | 5 | 确认航迹连续 5 帧未关联才消亡，单帧漏检不致命 |
| `Gate` | 9.21 | 关联门限（2D 卡方 99% 分位，马氏距离平方） |
| `MeasNoise` | 4 | 量测噪声方差（σ=2） |
| `ProcessNoise` | 0.5 | 过程噪声强度 |

## 遮挡处理策略

目标被遮挡（无观测）时，确认航迹进入**滑行（coast）**状态：只做预测不做校正，
`Misses` 计数递增，协方差随预测步数增大。只要遮挡时长 < `MaxMisses`，
航迹就不会消亡；目标重现时，放宽后的门限能覆盖其位置，观测经全局关联
**回到原航迹**（记录 `recovered` 事件），而不是新建一条航迹。
遮挡持续超过 `MaxMisses` 帧才判定目标真正消失（`deleted` 事件）。
演示场景中目标 3 在第 45–48 帧被遮挡（4 帧 < 阈值 5），第 49 帧恢复原航迹；
第 90 帧起真正消失，第 94 帧（连续 5 帧漏检）判定消亡。

## 测试覆盖

- `tracker/hungarian_test.go`：匈牙利算法对照暴力全排列最优解；贪心失败而全局最优胜出的用例；不可行匹配被拒绝、双方保持未关联。
- `tracker/tracker_test.go`：新航迹连续帧确认阈值；随机杂波永不确认且暂态航迹有界；确认航迹单帧漏检不消亡、连续阈值帧漏检才消亡；遮挡后恢复原航迹（`recovered` 事件、无新航迹）；超门限观测不被强制关联；解析构造交叉场景无身份交换。
- `scenario/scenario_test.go`：含噪声与杂波的完整场景中，交叉双目标身份纯度 ≥ 90% 且 ID 切换为 0；整体身份保持率 ≥ 90%（实测 100%）；遮挡恢复不产生新航迹；新生确认帧与消亡帧严格符合阈值推算。
